# Diabetes-Risk-Analysis
For this project, I created a synthetic dataset containing variables such as glucose level, age, BMI, and daily steps. I then created a risk score and used it to generate a binary diabetes-risk outcome. A Random Forest Classifier was trained to learn patterns in the data and predict whether an individual belongs to the low-risk or high-risk group.

The main goal of this project is to practice the complete machine-learning workflow, from creating and exploring data to training, evaluating, and interpreting a model.

Important: The dataset and risk formula used in this project are synthetic and are not intended for medical diagnosis or real-world clinical decision-making.
